# RezoneVPN — прототип 0.6.3

## Автообновления

Windows-приложение теперь собирается как пользовательский NSIS-установщик, а не portable EXE. В упакованном приложении `electron-updater` проверяет GitHub Releases, загружает новую версию в фоне и предлагает перезапуск; отложенная установка выполняется при закрытии приложения.

Настроен репозиторий обновлений `Rexaonygrief/123123123sdfs`. Чтобы выпускать обновления текущей версии:

1. Убедитесь, что репозиторий и его Releases доступны клиентам. Исходники можно держать отдельно; в приложение не вшивайте секретные токены.
2. Загрузите обновлённые исходники в целевой репозиторий `Rexaonygrief/123123123sdfs`.
3. Для этой версии после коммита отправьте тег `v0.6.3`. Workflow соберёт NSIS-установщик Windows x64 и прикрепит `latest.yml`.
4. Установленное NSIS-приложение сможет получить 0.6.3 через автообновление. Пользователям старой portable-сборки нужно один раз установить NSIS Setup вручную; затем обновления будут приходить через приложение.
5. Для последующих выпусков синхронно меняйте версию в `package.json`, `renderer.js` и журнале, затем отправляйте соответствующий тег `v*`.

GitHub Actions использует свой `GITHUB_TOKEN` из секретов workflow для публикации. Токен не хранится в приложении и не должен добавляться в исходники. Релизы, выпущенные в закрытый репозиторий, недоступны клиентам без авторизации; для широкой раздачи используйте публичный репозиторий релизов или отдельный HTTPS-сервер обновлений.

## Ограничения прототипа

- VPN-туннель не реализован: выбор локаций, режима и сервисов не маршрутизирует трафик; системный прокси не настраивается. Для реального VPN нужны протокол/клиент, серверные конфигурации и системная интеграция.
- Каталог товаров локальный и не синхронизируется с сайтом.
- Авторизация и аккаунты хранятся локально и не являются production-системой. Не используйте настоящие пароли или чувствительные данные.

## Проверка внешнего IP

Карточка «Проверка сети» получает внешний IP и приблизительную страну/регион/город через HTTPS API `ipapi.is`, без ключа. Результаты геолокации приблизительны, а IP передаётся стороннему сервису. См. [документацию API](https://ipapi.is/developers.html). Переключатель «Скрыть IP» хранится локально.

## Сборка Windows x64

```bash
npm ci
npm start
npm run dist:win
```

Обычная сборка создаёт установщик в `dist/`, не публикуя его. Публикация производится workflow при отправке тега `v*`; в нём задано разрешение `contents: write`.
